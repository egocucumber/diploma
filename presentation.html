Приоритет commit-истории (tryCommitFix)

  • Для каждой пары до/после из коммита вызывается /detect
  • Если реальный фикс снижает сложность — используется как рефакторинг (confidence=0.92)
  • Иначе fallback на StarCoder2+LoRA

Преимущества разделения агентов

  • CodeBERT-детекция работает на CPU без GPU
  • Clean Code пропускает /refactor — экономия ресурсов
  • Паттерн-специфичный фрагмент: для каждого запаха вырезается минимальный контекст

Обучение CodeBERT-классификатора

  • Базовая модель: microsoft/codebert-base (125M параметров)
  • Датасет: 6 237 примеров из 13 репозиториев
  • Размечено статическим анализатором + синтетика для редких классов
  • 15 классов, взвешенный CrossEntropy (балансировка)
  • 5 эпох, lr=2e-5, batch=16, max_length=256
  • Точность (weighted F1): 66%

Паттерн-специфичный фрагмент

  • Long Parameter List → только сигнатура функции (~8 строк)
  • Deep Nesting → блок вокруг самого глубокого уровня
  • Empty Catch / Commented Code → 10 строк контекста
  • God Function / Long Method → до 60 строк наиболее сложной функции

StarCoder2-3B + LoRA — рефакторинг

Датасет (commit-пары)

  • 52 репозитория, PyDriller, 5 языков
  • Пары: код до коммита → код после
  • Фильтр: 50–1500 символов, изменение 10–80%

Параметры дообучения

  • bigcode/starcoder2-3b (3B параметров)
  • LoRA r=16, α=32, 3 эпохи, lr=2e-4
  • fp16, batch 4 × grad_accum 8 = eff. 32
  • max_length=512, генерация до 512 токенов

Выбор фрагмента для рефакторинга

  • При файле более 40 строк — выбирается наиболее сложный фрагмент
  • Python: обход дерева разбора, оценка = строки + CC × 3
  • JS / Go: поиск функций, выбор самой длинной
  • Ограничение фрагмента — 60 строк
  • Позиция фрагмента сохраняется для вставки обратно

Показатель уверенности

Для каждого сгенерированного токена вычисляется вероятность по функции softmax. Уверенность — среднее этих вероятностей. Чем выше значение, тем надёжнее предложенный рефакторинг.

def process(data, flag, n,
            timeout, retry):
    result = []
    for i in range(n):
        if flag == True:
            if timeout > 30:
                if retry > 3:
                    for item in data:
                        if item > 0:
                            result.append(
                                item * 2)
    return result

def process(data, flag, n,
            timeout, retry):
    if not flag or timeout <= 30:
        return []
    if retry <= 3:
        return []
    return [item * 2
            for item in data
            if item > 0]

Анализ

Ограничения и решённые технические проблемы

Ограничения системы

  • CodeBERT: weighted F1 66% — Long Method / God Function / High Complexity похожи и путаются
  • StarCoder2: seq2seq не гарантирует компилируемость вывода
  • Контекстное окно 512 токенов — решено паттерн-специфичной фрагментацией
  • Не поддерживаются языки вне датасета (Ruby, Rust и др.)

Решённые технические проблемы

  • Галлюцинация модели на сложных функциях — добавлен детектор зацикливания (повтор строк > 40%)
  • Нефункциональные фрагменты вызывали галлюцинации — добавлена проверка наличия функции
  • Паттерн-специфичный фрагмент: Long Parameter List передаёт только сигнатуру, не всё тело
  • Токены доступа хранились в открытом виде — переведены на AES-256-GCM
  • SQLite не масштабировался — мигрировали на PostgreSQL в отдельном контейнере
Система предоставляет предложения — финальное решение о применении остаётся за разработчиком
